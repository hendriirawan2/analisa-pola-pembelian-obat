# Link untuk Ditempel ke Google Sites

Setelah aplikasi di-upload ke GitHub Pages, link halaman utamanya akan berbentuk:

```text
https://USERNAME.github.io/NAMA-REPOSITORY/
```

Untuk halaman database yang bisa diedit tampilannya, gunakan:

```text
https://USERNAME.github.io/NAMA-REPOSITORY/database.html
```

Contoh jika username GitHub Anda `hendriirawan` dan repository bernama `apotek-smf-1-duku`:

```text
https://hendriirawan.github.io/apotek-smf-1-duku/database.html
```

## Cara Tempel di Google Sites

1. Buka Google Sites.
2. Klik `Insert`.
3. Klik `Embed`.
4. Pilih tab `By URL`.
5. Tempel link `database.html` dari GitHub Pages.
6. Klik `Insert`.
7. Atur ukuran kotak embed agar tabel terlihat nyaman.

## Fungsi Halaman Database

Halaman `database.html` bisa:

- menempel URL Google Apps Script
- memuat data dari Google Sheets
- mengubah data transaksi langsung dari tampilan
- menambah baris transaksi
- menghapus baris transaksi
- menyimpan data kembali ke Google Sheets
- download data sebagai CSV

Pastikan Google Apps Script sudah dibuat dan dideploy sesuai panduan:

```text
PANDUAN_GOOGLE_SHEETS.md
```
